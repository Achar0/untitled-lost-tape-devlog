# Untitled Lost Tape — devlog

Public development log for **Untitled Lost Tape**, a 2D pixel-art narrative adventure about chasing a lost song from an old internet forum, and the slow, uneven work of climbing out of a depressive state.

This repo does **not** contain the game's source code, art, or writing — the game itself is developed in a private repository. What lives here is process: design notes, technical write-ups, screenshots, and honest reflection on how the thing gets made.

- **Engine**: Godot
- **Platform**: Desktop, with a Steam release planned
- **Status**: Early concept / pre-production
